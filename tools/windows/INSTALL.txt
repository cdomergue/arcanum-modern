ARCANUM MODERN - WINDOWS x64

1. Install your own copy of Arcanum (version 1.0.7.4).
2. Extract this ZIP into its game folder, next to Arcanum.exe and arcanum1.dat.
3. Open "renaissance-launcher.exe" or "Play Arcanum Renaissance.bat".

No compiler, Python, separate SDL installation or administrator rights are needed
for players. Windows 10/11 x64 is the intended target. Use a writable game folder.
The original Arcanum.exe is kept. No original game archives, saves or personal
settings are included in this ZIP. The game reads your installed language files.

Open Options to change fullscreen, resolution, controls, gameplay and audio.
The modern interface and turn-based combat are enabled by default. The world
uses an independent rendering resolution; the interface stays sharp when zooming.

The launcher checks for stable releases, displays their release notes, and
installs updates before starting the game. Choose "Play without updating" to
skip, or disable automatic launch to read the notes. English and French are
available. You can play without an internet connection. Updates preserve saves,
settings, notebook files, custom portraits and backgrounds. Failed updates are
rolled back; interrupted installations are recovered at the next launch.
You can also update manually by extracting a newer ZIP while the game is closed.
Back up saves before trying a different engine version. This version remains
experimental; multiplayer and compatibility with other binary patches are untested.
Bink cinematics use the bundled 64-bit decoder.

This is a modified version of Arcanum Community Edition by Alex Batalov:
https://github.com/alexbatalov/arcanum-ce
Changes include the modern interface, presentation and tactical controls.
See licenses/ for upstream and third-party notices. This package contains no
commercial Arcanum game data. Distribute it free of charge for non-commercial use.

On first launch, HD local maps are generated from your installed game files.
A progress bar shows preparation. Allow about 8 GB plus temporary working space
for Arcanum and Vormantown. Choose "Play now" to skip preparation; it resumes
next time. Completed maps are reused. No extra downloads or tools are needed.
