ARCANUM MODERN - LINUX x64

Extract the entire ZIP into your own Arcanum 1.0.7.4 installation, beside
arcanum1.dat. Keep the modern-ui directory. Use a writable game folder.
Run ./"Play Arcanum Renaissance.sh" from a terminal, or launch the script through
your file manager. If the archive tool discarded executable permissions, run:

  chmod +x arcanum-modern "Play Arcanum Renaissance.sh"

The release workflow builds on Ubuntu 22.04 for x86-64 Linux with glibc 2.35
or newer. Locally generated packages record their minimum glibc version in
ArcanumModern/manifest.json. musl-based distributions are not supported.
SDL and the audio codecs are linked into the executable. Your desktop still
needs X11 or XWayland, graphics drivers (Vulkan by default) and an audio backend
such as PulseAudio or ALSA. No separate SDL installation is required.

For a windowed session:
  ./"Play Arcanum Renaissance.sh" -window -geometry=1280x720

The launcher tries Vulkan first. If it exits with a segmentation fault before
reaching the main menu, the launcher retries once using X11 software rendering
with framebuffer acceleration disabled. It preserves the first attempt in
modern-launch-vulkan.log and writes the retry to modern-launch.log. Crashes
at the menu or during gameplay do not trigger an automatic restart.

To use software rendering directly:
  SDL_RENDER_DRIVER=software ./"Play Arcanum Renaissance.sh"

Selecting a renderer explicitly disables automatic retry. With software selected,
X11 and disabled framebuffer acceleration are defaults; SDL_VIDEO_DRIVER and
SDL_FRAMEBUFFER_ACCELERATION can override them. Use Options for game settings.

This ZIP contains no game data, saves, generated maps or personal preferences.
Close the game before extracting an update. Keep your existing modern-ui INI
and notebook files and the modules/<module>/Save directory. Back up saves before
trying an experimental engine. The original Arcanum executable is not replaced.

Based on Arcanum Community Edition by Alex Batalov:
https://github.com/alexbatalov/arcanum-ce
See licenses/ for upstream and third-party license notices.

On first launch, HD local maps are generated from your installed game files.
A progress bar shows preparation. Allow about 8 GB plus temporary working space
for Arcanum and Vormantown. Choose "Play now" to skip preparation; it resumes
next time. Completed maps are reused. No extra downloads or tools are needed.
