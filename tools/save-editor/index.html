    POUR REPRENDRE LA PARTIE

    Trois gestes, une nouvelle copie.

    1. Gardez l’original. Faites une copie des fichiers de votre emplacement de sauvegarde avant de le remplacer.
    2. Importez, puis ajustez. Ouvrez une seule paire de fichiers. Les valeurs d’origine restent visibles à côté de vos changements.
    3. Exportez et remplacez. Fermez le jeu, décompressez le ZIP, puis placez les fichiers dans le dossier Save. Conservez les .gsi et .bmp d’origine si vous ne les avez pas importés.
