    TO CONTINUE YOUR GAME

    Three steps to a new copy.

    1. Keep the original. Back up the files from your save slot before replacing them.
    2. Import, then adjust. Open one pair of files. Original values remain visible beside your changes.
    3. Export and replace. Close the game, extract the ZIP, then place the files in the Save folder. Keep the original .gsi and .bmp files if you did not import them.

    Supports TIG archives containing version 119 objects. Adding spells and skills does not spend available points; magic and technology aptitude counters are adjusted. The game still applies attribute and level restrictions. The editor does not complete training quests or edit full inventories, companions or derived effects. Changing experience does not automatically trigger a level-up.
