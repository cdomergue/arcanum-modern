## Native gamepad support

Play with an SDL-compatible controller: direct movement, combat targeting and menu navigation, with button prompts and vibration feedback. Radial menus give quick access to your abilities and the main game panels.

- Walk or run with the left stick, interact with nearby objects, and cycle combat targets with the right stick click.
- Navigate inventory, character sheets and options with the controller. Adjust vibration, stick dead zone and pointer speed in **Options > Key bindings > Gamepad**.
- On Steam Deck, select a Steam Input **Gamepad** layout. Mouse and keyboard remain available; text entry uses a keyboard or the on-screen keyboard.

See the [controller guide](https://github.com/cdomergue/arcanum-modern#controllers-and-steam-deck) for the full controls.

## For mod creators: ART Editor

The Windows WorldED package now includes ART Editor alongside WorldED and Script Editor. Preview sprites and animations, edit palettes and anchors, and import or export PNG sequences. Open it from WorldED's **Resources > ART editor** menu or run `art-editor.exe`.

[ART Editor guide](https://github.com/cdomergue/arcanum-modern/blob/v2.3.0/docs/art-editor.md)

Update through the Renaissance launcher or install the package for your platform into your existing Arcanum folder. Close the game before updating.
