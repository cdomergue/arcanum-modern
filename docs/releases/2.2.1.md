The launcher now includes a **Feedbacks** tab for sending comments and bug reports to the developer. Messages include only the text you enter and the launcher version; no saves, diagnostic logs or player statistics are sent.

The tab also links to the project's GitHub repository, with labels in English and French. Automatic game startup pauses while you write your feedback.

This release updates the launcher only. Update through the Renaissance launcher or install the package for your platform into your existing Arcanum folder. Close the game before updating and back up your saves.
